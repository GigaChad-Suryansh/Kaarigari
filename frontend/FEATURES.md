# Kaarigari frontend flows

## Customer
- Discover curated crafts
- Search by craft, material, or place
- Filter by category
- Open product details and maker story
- Save products to wishlist
- Add products to cart
- Review cart and checkout
- Track orders

## Artisan
- Phone/OTP entry
- Dashboard with products, orders, revenue
- Voice-first product capture
- AI-assisted name/category extraction
- AI long description and cultural story
- Image enhancement workflow
- Offline draft queue
- Inventory and order management
- AI business insights

The current MVP exposes the first pieces of these flows and is designed so the production screens can consume the backend API without changing the visual system.
