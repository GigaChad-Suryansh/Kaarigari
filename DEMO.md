# Kaarigari Demo

Kaarigari is designed to be demonstrable without creating Twilio, Cloudinary, Razorpay, or database accounts.

## Run

Open `index.html` directly for the static customer/artisan demo. For the API, run the backend with Node 20.

## Demo OTP

`123456`

## Demo capabilities

- Customer catalog/search
- Artisan dashboard
- Phone/OTP flow
- Browser voice input
- AI-style classification and cultural description fallback
- Product photo upload and marketplace enhancement preview
- Offline draft persistence and reconnect sync
- Demo checkout/order flow
- Business insights

Production providers are optional and can be enabled through environment variables. Never commit real credentials.
