# Kaarigari

**Made with a voice. Built for every artisan.**

Kaarigari is an artisan-first marketplace concept with separate customer and artisan experiences. This repository contains the demo MVP and its frontend foundation.

## Included in the MVP

- Customer marketplace with search and craft categories
- Artisan/seller dashboard
- Role-based phone + OTP demo authentication
- Voice-first product creation using browser speech recognition
- AI-style smart catalog generation flow
- Product photo upload and enhancement workflow placeholder
- Offline-first draft persistence with reconnect synchronization
- Artisan business insights and order/revenue dashboard
- Responsive mobile-first visual system inspired by the Kaarigari reference design

## Run

Open `index.html` in a browser, or serve the repository with any static HTTP server.

For a production deployment, connect the UI to real authentication, storage, database, speech-to-text, image enhancement, and generative AI services. Never put secret API keys in browser code.
